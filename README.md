# Devis BTP

Calculateur de devis pour les travaux de BTP, en HTML, CSS et JavaScript.

## Fonctionnalités

- Ajout de lignes (désignation, quantité, prix unitaire)
- Suppression d'une ligne
- Calcul automatique du total HT, de la TVA (19,25 %) et du total TTC en FCFA
- Refus des lignes incomplètes (champ vide, quantité ou prix à 0)
- Sauvegarde automatique dans le navigateur (localStorage)
